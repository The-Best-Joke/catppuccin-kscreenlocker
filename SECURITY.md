### Reporting A Vulnerability

If you have any reason to believe that there are security vulnerabilities in
this project, please report them to **[alejandro.s@berkeley.edu](mailto:alejandro.s@berkeley.edu)**.

I will aim to respond as quickly as possible, but note that the above mailbox
is **not** monitored 24/7. If the report is confirmed, a fix will be deployed
as soon as is reasonable given the complexity of the issue.

GitHub's [private vulnerability reporting][gh-pvr] is also enabled on this
repository as an alternative reporting channel.

[gh-pvr]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability
